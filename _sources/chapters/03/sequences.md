# DataFrames and Working with Data

Pandas gives us tools to load, inspect, clean, and summarize tables. These readings
introduce the tools through complete worked examples.

- **For Fall 2026 Week 2:** [Pandas, Data Cleaning, and Introductory EDA](2/pandas-cleaning-eda.ipynb)
  follows a fictional study-space survey from a messy CSV to a careful interpretation.
  Read this alongside Lab 01.
- **Another introduction:** [Tabular Data in Pandas](1/tabular.ipynb) explores a
  Pokémon dataset, including previews, summary statistics, and sorting.

If Python syntax is unfamiliar, start with [Introduction to Python](../02/intro_python.md).
