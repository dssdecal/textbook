5.2.1. What is Pandas?#

Pandas (originally short for Panel Data, though everyone just thinks of the animal 🐼) is a Python library built for data manipulation and analysis. It gives you powerful, flexible data structures that make working with structured data — think spreadsheets, CSV files, or database tables — fast and intuitive.

Why is pandas so popular?

  • It handles messy, real-world data gracefully: missing values, mixed types, inconsistent formatting

  • It reads from many file formats: CSV, Excel, JSON, SQL databases, and more

  • It has rich tools for filtering, grouping, reshaping, and summarizing data

  • It integrates with the broader Python data science ecosystem: NumPy, Matplotlib, scikit-learn, etc.

Pandas is built on top of NumPy, which we’ll touch on later. For now, think of pandas as adding a friendlier, more expressive layer on top of NumPy’s raw numerical power.

Installing pandas: If working locally, run pip install pandas. In Google Colab or most Jupyter environments, it comes pre-installed.

5.2.2. Series#

A Series is the simplest pandas data structure. Think of it as a single column of data — like one column in a spreadsheet.

More precisely, a Series is a one-dimensional labeled array. It has two parts:

  • Values: the actual data (numbers, strings, booleans, etc.)

  • An index: a label for each value (by default: 0, 1, 2, … but can be anything meaningful)

The index is what makes a Series more powerful than a plain Python list. It lets you access data by label rather than just position — very useful when your data has meaningful identifiers like dates, names, or country codes.

Real-world examples of a Series:

  • Daily high temperatures for a week

  • Ages of patients in a medical study

  • Stock prices over time

  • Responses to a single survey question

Boolean Filtering & Arithmetic on Series

You can apply comparisons (>, <, ==, !=, >=, <=) to a Series to get a Boolean mask, then use that mask to filter values. This is much more readable than a loop.

Filtering examples:

s = pd.Series([10, 20, 30, 40, 50], index=["a","b","c","d","e"])

# Boolean mask
print(s > 25)         # False, False, True, True, True

# Filter using the mask
print(s[s > 25])      # c 30, d 40, e 50

# Combine conditions
print(s[(s > 15) & (s < 45)])   # b 20, c 30, d 40

Arithmetic (vectorized — no loops needed):

print(s * 2)          # All values doubled
print(s + 100)        # 100 added to each value
print(np.sqrt(s))     # Square root of each value (uses NumPy)

5.2.3. DataFrames#

If a Series is a single column, a DataFrame is an entire table — rows and columns, like a spreadsheet or a database table. It is the most important pandas data structure, and the one you’ll use most.

A DataFrame is a two-dimensional labeled data structure where:

  • Each column is a Series (and can have a different data type)

  • Each row has an index label

  • Columns also have names

You can think of a DataFrame as a dictionary where each key is a column name and each value is a Series — all sharing the same row index.

Real-world examples of a DataFrame:

  • A spreadsheet of student grades across multiple assignments

  • A table of patient records: age, weight, blood type, diagnosis

  • A dataset of countries with population, GDP, and life expectancy

  • Any CSV file you’d open in Excel

.loc vs .iloc — Label vs Position

This distinction trips up nearly every pandas beginner. Here’s the rule:

Accessor

Selects by

End of slice

.loc[row, col]

Label (index value or column name)

Inclusive

.iloc[row, col]

Integer position (0-based, like a list)

Exclusive

.loc examples:

df.loc[3]                        # Row whose index label is 3
df.loc[1:3, "name":"gpa"]        # Rows 1–3 (inclusive), columns name through gpa (inclusive)
df.loc[df["gpa"] > 3.5, "name"] # Filter rows + select one column
df.loc[:, ["name", "major"]]     # All rows, two specific columns

.iloc examples:

df.iloc[0]           # First row by position
df.iloc[-1]          # Last row by position
df.iloc[0:3, 0:2]    # Rows 0–2, columns 0–1 (exclusive end)
df.iloc[:, 1]        # All rows, second column

Setting values with .loc:

# Change a specific cell
df.loc[2, "gpa"] = 4.0

# Set an entire column for filtered rows
df.loc[df["year"] == 1, "honor_roll"] = False

5.2.4. NumPy Arrays#

Before diving into cleaning, it’s worth understanding pandas’ relationship with NumPy.

NumPy (Numerical Python) is the foundational library for numerical computing in Python. Its core object is the ndarray (n-dimensional array) — a fast, efficient grid of values, all of the same data type.

Pandas is built on top of NumPy. Under the hood, every Series and DataFrame column stores its data as a NumPy array. This means:

  • Pandas inherits NumPy’s speed for numerical operations

  • You can easily convert between pandas and NumPy objects

  • Many NumPy functions work directly on pandas objects

When to use NumPy vs. pandas:

Use NumPy when…

Use Pandas when…

Pure numerical data (matrices, vectors)

Data has mixed types (strings + numbers)

Linear algebra, matrix math

Data has meaningful row/column labels

Writing scientific simulations

Reading/writing CSV, Excel, JSON

Maximum raw performance

Groupby, merge, pivot, time-series operations

In practice, you’ll use both together constantly.

5.2.5. Pandas Cleaning Functions#

In the real world, data is almost never clean when you first receive it. Column names are inconsistent, values are missing, data types are wrong, and rows may be duplicated. Data cleaning is the process of identifying and fixing these problems before you analyze anything.

Experienced analysts often say that 80% of data work is cleaning — and pandas provides an excellent toolkit for it.

We’ll walk through the most essential functions using a realistic, intentionally messy dataset:

  1. Exploring data — head(), tail(), shape, columns, index, info(), describe()

  2. Selecting data — loc, iloc, column selection, boolean filters

  3. Handling missing data — isnull(), dropna(), fillna()

  4. Modifying data — renaming columns, fixing types, standardizing strings

  5. Sorting and deduplication — sort_values(), drop_duplicates()

# Let's create a realistic messy dataset — survey data collected from students.
# Notice the problems intentionally baked in:
#   - Student 102 (Iana) appears twice (duplicate)
#   - Column name '  Name  ' has extra spaces
#   - 'MAJOR' column has inconsistent capitalization: "ds", "DS", "CS", "economics", "Biology"
#   - 'year' column has "third" (a string) instead of 3
#   - Several missing values across multiple columns

5.2.5.2. Step 2: Selecting Data with loc and iloc#

You’ll constantly need to slice specific rows, columns, or individual cells from a DataFrame. Pandas gives you two primary tools:

  • .loc[row_label, col_label] — selects by label (the index value or column name). Slicing with .loc is inclusive on both ends.

  • .iloc[row_position, col_position] — selects by integer position (like Python list indexing). Slicing with .iloc is exclusive of the end (standard Python behavior).

A common confusion: with the default integer index, .loc[2] and .iloc[2] look the same. They differ once you change the index — and understanding the distinction will save you from subtle bugs.

# --- .loc examples ---

# Single row by label
print("Row with label 0:")
print(df.loc[0])
print()

# Rows 0-2 (INCLUSIVE) and specific columns
print("Rows 0-2, Name and GPA:")
print(df.loc[0:2, ["  Name  ", "GPA"]])
print()

# Boolean mask — filter rows where GPA > 3.7
print("Rows where GPA > 3.7:")
print(df.loc[df["GPA"] > 3.7])

5.2.5.3. Step 3: Handling Missing Data#

Missing data is the most common issue you’ll encounter. Pandas represents missing values as NaN (Not a Number) or None.

Your two main options:

  1. Drop the offending rows or columns

  2. Fill the missing values with something meaningful

Which you choose depends on context. Dropping is safer but loses data. Filling preserves data but introduces assumptions — a mean GPA fill is very different from a median fill if your distribution is skewed.

Handling Missing Data in Detail

Pandas uses NaN (Not a Number — from NumPy) and None interchangeably to represent missing values. The key functions are:

df.isnull() / df.notnull()

  • Returns a DataFrame of the same shape filled with True/False

  • isnull() → True where value is missing

  • notnull() → True where value is present

  • Most useful pattern: df.isnull().sum() to count missing values per column

df.isnull()           # Full boolean DataFrame
df.isnull().sum()     # Count NaN per column
df.isnull().sum() / len(df) * 100  # % missing
df[df["gpa"].isnull()]  # Rows where GPA is missing

df.dropna(axis=0, how='any', subset=None, inplace=False)

Parameter

Options

Meaning

axis

0 (rows) or 1 (columns)

What to drop

how

'any' or 'all'

Drop if any NaN vs. all NaN

subset

List of column names

Only check these columns

inplace

True / False

Modify in place vs. return new object

 
df.dropna()                          # Remove rows with ANY missing value
df.dropna(how='all')                 # Only remove rows that are ENTIRELY empty
df.dropna(subset=["name", "gpa"])    # Remove rows missing name OR gpa
df.dropna(axis=1, how='all')         # Drop columns that are completely empty

5.2.5.4. Step 4: Modifying Data#

Now let’s clean up the structural problems: inconsistent column names, dirty string values, and wrong data types.

Modifying Data in Detail

df.rename(columns={old: new}, index={old: new}, inplace=False)

Renames specific columns or index labels. Uses a dictionary to map old names to new names.

Bulk column normalization

A common real-world pattern — fix all column names in one line:

df.columns = df.columns.str.strip().str.lower().str.replace(" ", "_")

# "Student ID" → "student_id"
# "Extra Column" → "extra_column"

df.drop(columns=[], index=[], inplace=False)

Removes columns or rows.

df.drop(columns=["col1", "col2"])              # Remove multiple
df.drop(index=[0, 5])                          # Remove rows by label

df["col"].astype(dtype)

Converts a column to a different data type.

df["year"].astype(int)          # String/float → integer
df["gpa"].astype(float)         # Object → float
df["student_id"].astype(str)    # Number → string (for joining/merging)

df["col"].replace({old: new})

Substitutes specific values in a column. Cleaner than a loop.

df["year"].replace("third", 3)
df["major"].replace({"Cs": "CS", "BIOLOGY": "Biology"})

df["col"].map({key: value})

Transforms each value using a dictionary or function. Any value not in the dictionary becomes NaN.

df["name"].map(str.upper)                              # Function mapping

5.2.6. Introductory Exploratory Data Analysis#

Use these questions alongside the inspection, cleaning, and grouped summaries above. EDA starts before cleaning and continues afterward.

5.2.6.1. What is EDA?#

Exploratory Data Analysis (EDA) is essential for understanding our datasets as it reveals underlying trends in our data, transforming it from messy numbers into clear insights. Many people working in data science roles report that this is the process that makes up most of their responsibilities!

EDA is the process of familiarizing ourselves with a new dataset before performing more advanced analysis or modeling. Through iterative EDA, we can better understand our variables, identify problems in the dataset, and discover potential hypotheses.

5.2.6.2. What should we look for during EDA?#

When performing EDA, you can reference a “checklist” of things to consider when examining your data.

Getting to know the data table columns and their types

  • Each column represents a variable in your data, and you should start by identifying what data / storage type the columns are. Data types tell you how each variable is stored in memory, and some data types include integers, floating points, booleans, and strings. You should also determine if columns represent quantitative or categorical variables.

Detecting missing values and outliers

  • Identify and handle missing data carefully, noting where and why values are missing; avoid blindly dropping records since this can introduce bias. Instead, consider strategies like keeping NaNs or using imputation only after understanding the cause of missingness.

  • Imputation is the process of inferring missing values using other data available in the dataset. Here are some common imputation methods: average imputation (replace missing values with the average value for that field), regression imputation (develop a model to predict missing values and replace with the predicted value from the model), and random imputation (replace missing values with random values).

Looking at summaries, distributions, and relationships between variables

  • How is the data in each variable spread? Summary statistics like the mean or standard deviation and visualizations can better clarify the shape of your data. Visualizations can be especially helpful in exploring any potential relationships between two variables or columns in your data.

5.2.6.3. Basic EDA with Pandas#

EDA is most commonly performed with pandas, a Python library for working with tabular data. Below are some common Pandas notation and functions used during the EDA process.

Getting to know the data table columns and their types

  • import pandas as pd : Pandas is shortened to pd, just like how NumPy is shorted to np.

  • df refers to “dataframe,” which is essentially the term to refer to tables.

  • pd.read_csv('INSERT YOUR FILE NAME.csv') Most datasets are comma-separated values (CSV) files, and this function loads a CSV file into an easily-manipulated dataframe format.

  • df.shape Returns the # rows x # columns in the dataframe

  • df.dtypes Returns the data types for each column

Manipulating the data

  • df.sort_values(by='COL', ascending=True) Sorts rows by the values in column 'COL'.

  • df.groupby(by='COL') “Categorizes” the table based on unique values in the column 'COL', applying a function to the collected values.

  • pd.merge() Combines two or more dataframes together based on common values in columns

Detecting missing values and outliers

  • df.isna() Returns a dataframe with True / False values indicating whether a value is missing (None or NaN)

  • df.dropna() Drops rows with missing data

  • df.fillna(VALUE) Fills missing values with the passed in VALUE

Looking at summaries, distributions, and relationships between variables

  • df.describe() Returns summary statistics for all numeric columns

  • df['col'].mean(), df['col'].min(), and df['col'].max() summarize a selected numerical column.

5.2.7. 🎉 Recap#

You’ve covered a lot of ground! Here’s a summary of everything in this notebook:

Core Data Structures

  • A Series is a labeled 1D array — like a single spreadsheet column

  • A DataFrame is a labeled 2D table — like an entire spreadsheet

  • Pandas is built on NumPy — fast under the hood, and easy to convert between them

Exploration

  • df.head() / df.tail() — preview first or last rows

  • df.shape — dimensions as (rows, cols)

  • df.columns / df.index — column names / row labels

  • df.info() — column types and missing value counts

  • df.describe() — summary statistics

Selection

  • df["col"] — select a column (returns Series)

  • df[["col1", "col2"]] — select multiple columns (returns DataFrame)

  • df.loc[row, col] — select by label (inclusive slicing)

  • df.iloc[row, col] — select by integer position (exclusive slicing)

  • df[df["col"] > value] — filter rows by condition

Cleaning

  • df.isnull().sum() — count missing values per column

  • df.dropna() — remove rows/cols with missing data

  • df.fillna(value) — fill missing values

  • df.rename(columns={...}) — rename specific columns

  • df.columns.str.strip().str.lower() — bulk normalize column names

  • df.drop(columns=[...]) — remove columns

  • df["col"].str.title() — fix string capitalization

  • df["col"].replace({...}) — replace specific values

  • df["col"].astype(type) — convert data type

  • df["col"].map({...}) — transform values using a dictionary

  • df.sort_values("col") — sort rows

  • df.drop_duplicates(subset="col") — remove duplicate rows

  • df.reset_index(drop=True) — rebuild a clean row index
